# Documentation

| Document | What it is for |
|---|---|

| [PLAN.md](PLAN.md) | The layered build order, kept as a record of the reasoning. |

`images/` holds the screenshots used by the README and tutorial.

## Reading order

If you want to **use** the tool, read `TUTORIAL.md` and stop there.

If you want to understand **why** it makes the choices it does — read-only
saves, a change journal instead of a backups folder, a warning attached to the
FPS switch — read `FINDINGS.md` first. The evidence explains the design better
than the design documents do.
